🔥 Firebase — Auth চালু করার নির্দেশ

১. Firebase Console → Authentication → Get started
২. "Email/Password" সাইন-ইন পদ্ধতি চালু করুন
৩. Firestore Rules আপডেট করুন:
match /pending/{id} { allow read: if request.auth != null; allow write: if request.auth != null; }
match /entries/{id} { allow read: if true; allow write: if true; }
match /users/{id} { allow read, write: if request.auth.uid == id; }
